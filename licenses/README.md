corresponde a cada modelo, de dónde sale y por qué se permite su uso está en
[docs/licencias-modelos.md](../docs/licencias-modelos.md).

| --- | --- |

| `FERPlus-MIT.txt` | Etiquetas FER+ de Microsoft con las que se entrenó el modelo FER+ |
