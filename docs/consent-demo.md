# EMOtv: consentimiento provisional de demostración

**Código:** EMOTV-CONSENT-DEMO-001 · **Versión:** v0.1

Este texto es una política **DEMO, NO APROBADA POR LA UNIVERSIDAD**. Se usa
únicamente para desarrollo y demostraciones con participantes informados. No
habilita un despliegue institucional real.

Si aceptas, EMOtv usará temporalmente la cámara de tu dispositivo para analizar
una expresión facial y sugerir una actividad corporal. El análisis automático
no es un diagnóstico psicológico. Los fotogramas se envían al servidor para su
procesamiento y no se almacenan como video; la sesión puede registrar la
expresión estimada, la actividad y su resultado.

Puedes no aceptar y seguir usando funciones que no requieran análisis facial.
También puedes revocar tu aceptación desde la página de consentimiento; desde
ese momento no se podrán iniciar nuevos análisis asociados a tu perfil.

Antes de cualquier uso real, la institución debe sustituir esta política por
un documento aprobado que detalle responsable, finalidad, retención,
destinatarios y mecanismos para ejercer derechos.
