Modelo de datos

Modelo de datos de EMOtv derivado de las migraciones Alembic: trece tablas de PostgreSQL agrupadas en identidad y consentimiento, análisis y contenido, y Emi, con sus claves primarias, foráneas y cardinalidades.

# clave primaria · → clave foránea. sessions.activity_id y consents.policy_version no tienen clave foránea para conservar el historial. No hay tablas de imágenes. Fuente de verdad: migrations/versions/ (ver docs/data-model.md).
